## `~/featured-work`

| Project | What it does | Stack |
|---|---|---|
| **Fathom** — _Final Year Project_ | LLM-powered malware-analysis framework on a **Mixtral-8×7B MoE** fine-tuned with 9 LoRA adapters; ingests CAPE sandbox reports and runs a swarm of 4 agents (threat-intel, ATT&CK enrichment, IOC correlation, family context) into analyst-grade reports. | `Python` `Mixtral` `Neo4j` `MinIO` `Next.js` |
| **Auron** — _Cybersecurity Lab Platform_ | Hybrid platform for secure-software education: Docker-based labs (DVWA, JuiceShop, Wazuh) + a browser extension for real-time cookie, CSP & phishing analysis. | `Docker` `React` `Extension` |
| **CyberPulse** — _AI Vulnerability Mgmt_ | Processes OpenVAS XML reports with live threat intel (NVD, Vulners, Shodan) and AI-driven severity prediction + automated remediation suggestions. | `Python` `OpenVAS` `Shodan` |
| **SecureBrave** — _Browser Forensics_ | Extracts history, decrypts saved passwords, bookmarks, cache & prefetch execution history from Brave, producing chain-of-custody reports. | `Python` `SQLite` `Go` |
| **REST API Security** — _BOLA & JWT_ | Demonstrates real API exploits (Broken Object Level Authorization, JWT misconfig) with documented mitigations. | `Node.js` `Burp Suite` |
